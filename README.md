# CampusTalk

Прогресивна веб-система асинхронної комунікації студентів і викладачів.

## Tech Stack

Frontend:
- React
- Vite
- TypeScript
- Zustand
- UnoCSS

Backend:
- Node.js
- Express
- MongoDB (Atlas)

## Структура

- client/ — frontend
- server/ — backend

## Запуск

### frontend
cd client
npm install
npm run dev

### backend
cd server
npm install
npm run dev
